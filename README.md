# Shah Bakhsh | AI Engineer Portfolio

A responsive personal portfolio for Shah Bakhsh, focused on AI engineering, agentic systems, LLM applications, and low-resource language technology.

## GitHub Pages

This repository is configured to publish the static website using GitHub Actions.

After enabling **Settings → Pages → Build and deployment → Source: GitHub Actions**, pushes to `main` deploy automatically.

## Files

- `index.html` — portfolio structure and content
- `theme.css` — responsive visual design
- `main.js` — navigation, scroll progress, and reveal interactions
- `favicon.svg` — site icon

## Local preview

Open `index.html` in a browser.
